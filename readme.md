### Задача:
1. Написать на языке С++ класс выполняющий функциональность модулятора QAM (QPSK, QAM16, QAM64) 
2. Написать на языке С++ класс выполняющий функциональность добавления гауссовского шума к созвездию QAM 
3. Написать на языке С++ класс выполняющий функциональность демодулятора QAM (QPSK, QAM16, QAM64) 
4. Написать последовательный вызов 1-3 для случайной последовательности бит для разных значений дисперсия шума 
5. Построить график зависимости вероятности ошибки на бит от дисперсии шума


### Запуск: 
* make - сборока проекта
* make run - запуск симуляции
* После запуска, необходимо выбрать модуляцию: QPSK / QAM16 / QAM64 (регистр не имеет значения)
* Результаты симуляции будут записаны в results/ название файла соответствует выбранной модуляции
* Для визуализации графика, необходимо запустить plot_graph.py

### Структура проекта:

* include/                    - Заголовочные файлы
    * config.hpp            - Конфигурация: enum qamMode, кол-во генерируемых битов
    * qam_modulator.hpp     - Модулятор: преобразует наборы бит в комлексные символы
    * qam_demodulator.hpp   - Демодулятор: преобразует комплексные символы в биты
    * awgn.hpp              - Наложение Аддитивного Белого Гауссовского Шума
    * utils.hpp             - Вспомогательное: генерация таблиц Созвездиq, генератор битов

* src/                        - Реализации(.cpp)
    * main.cpp              - Симуляция: перебор дисперсий шума, расчёт BER, запись результатов в файл
    * qam_modulator.cpp     - Алгоритм модуляции для QPSK / QAM16 / QAM64
    * qam_demodulator.cpp   - hard демодулятор на основе treshold
    * awgn.cpp              - Генерация шума с заданной дисперсией
    * utils.cpp             - Генераторы: таблиц созвездий и битов

* results/                    - Записываются выходные данные
* Makefile                    - автоматизация сборки: (сборка - make), (запуск - make run), (очистка - make clean)
* plot_graph.py               - Отрисовка графика зависимости вероятности ошибки на бит от дисперсии шума на python



### Модулятор:
* Из последовательности бит берёт нужное количество бит для модуляции 1 символа
* Набор бит преобразуется в индекс (вектора)
* Индекс подставляется в созвездие. Значение, находящееся в векторе по индексу и есть модулированный символ

### Демодулятор:
* Используемый демодулятор - жёсткое решение. Каждая ось (Real/Imag) демодулируется отдельно путём сравнения с фиксированными порогами

### Генератор бит:
* Генерирует случайные биты (работа осуществляется с vector<bool>, таким образом можно генерировать именно биты)

### Симуляция:
* Для получения более достоверной статистики, был использован метод Монте-Карло
